# text_on_path example

Arabic, Persian, Urdu, Hindi, Bengali and a Latin script hand on a circle and an S-curve: rigid placement, cluster by
cluster, beside text_on_path's joined placement, each measured, with a loupe on the join rigid placement opens widest.
Seals fitted by kashida, tracking or word spacing; and a zoomable view, sharp at any zoom, that saves SVG and PDF.

```sh
flutter run -d macos
```

The fonts in `fonts/` are bundled under the SIL Open Font License, Version 1.1 (texts beside them).
